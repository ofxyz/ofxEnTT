ofxEnTT
=======

![thumb](ofxaddons_thumbnail.png)

ofxEnTT includes (Not wraps!) the [EnTT](https://github.com/skypjack/entt) entity manager as an OpenFrameworks plugin.

## Setup

Simply include the single header file as originally intended:

    #include <entt.hpp>


## EnTT Version

 - 3.16.0

> [ofxEnTTKit](https://github.com/ofKitty/ofxEnTTKit) contains all openFrameworks objects — nodes, cameras, meshes, materials, lights, shaders, textures, FBOs, images, video, audio, fonts, paths, polylines, serial I/O, and related drawing helpers as ECS-friendly components.
